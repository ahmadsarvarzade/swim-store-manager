# مدیریت فروشگاه — نسخهٔ محلی و قابل نصب

یک برنامهٔ فارسی و راست‌به‌چپ برای مدیریت فروشگاه، کالاها، انبار، سفارش‌ها و گردش مالی. برنامه با HTML/CSS/JavaScript ساده ساخته شده و برای استفادهٔ روزمره به نصب نرم‌افزار یا سرویس خارجی نیاز ندارد.

## امکانات فعلی

- داشبورد فروش، صندوق، موجودی و هشدار کالاهای کم‌موجود
- تعریف کالا با کد SKU، دسته‌بندی، واحد، قیمت خرید، قیمت فروش، موجودی و حد هشدار
- ثبت ورود، خروج و اصلاح موجودی همراه با تاریخچهٔ گردش انبار
- ثبت فاکتور خرید از تأمین‌کننده، افزایش موجودی و ثبت پرداخت کامل یا بخشی از فاکتور
- ثبت سفارش چندقلمی، تخفیف، هزینهٔ ارسال، دریافت کامل یا بخشی از وجه و کنترل موجودی پیش از فروش
- پیگیری وضعیت سفارش، چاپ جزئیات، ثبت دریافت تکمیلی و لغو سفارش همراه با برگشت موجودی و ثبت بازپرداخت
- پروندهٔ مشتریان و مشاهدهٔ سابقهٔ خرید و ماندهٔ دریافتنی
- ثبت هزینه‌های جاری و تراکنش‌های دستی دریافت/پرداخت
- گزارش مدیریتی فروش، بهای تمام‌شده، سود ناخالص، هزینه‌ها و بدهی/مطالبات
- خروجی فهرست کالاها به CSV و پشتیبان کامل JSON با قابلیت بازیابی
- رابط واکنش‌گرا برای نمایشگر Mac، iPhone و iPad
- قابلیت نصب PWA و کارکرد آفلاین پس از بارگذاری اولیه و کش‌شدن فایل‌های برنامه

## اجرای سریع روی macOS

۱. فایل ZIP را از حالت فشرده خارج کن.
۲. روی `Start-Mac.command` دوبار کلیک کن. اگر macOS اجرای آن را مسدود کرد، روی فایل راست‌کلیک و **Open** را انتخاب کن.
۳. برنامه در مرورگر با نشانی `http://127.0.0.1:8765` باز می‌شود. پنجرهٔ Terminal را تا زمانی که از برنامه استفاده می‌کنی نبند.
۴. برای نصب به‌صورت اپ، در Safari از دکمهٔ Share گزینهٔ **Add to Dock** را انتخاب کن؛ این قابلیت در macOS Sonoma 14 و نسخه‌های جدیدتر پشتیبانی می‌شود. در مرورگرهای دیگر هم می‌توان گزینهٔ Install app را به‌کار برد.

روش جایگزین برای اجرا:

```bash
cd swim-store-manager
python3 -m http.server 8765 --bind 127.0.0.1
```

سپس در مرورگر به `http://127.0.0.1:8765` برو.

## نصب روی iPhone / iPad

iOS اجازه نمی‌دهد این پوشه مثل یک فایل اجرایی مستقل از داخل Files اجرا شود. برای نصب واقعی PWA باید فایل‌ها روی یک وب‌سایت دارای HTTPS قرار بگیرند؛ مثلاً GitHub Pages:

۱. یک Repository در GitHub بساز و تمام فایل‌های داخل این پوشه را در ریشهٔ آن بارگذاری کن.
۲. در Repository به **Settings → Pages** برو و انتشار از شاخهٔ `main` و پوشهٔ `/root` را فعال کن.
۳. پس از ساخته‌شدن نشانی HTTPS، آن را در Safari آیفون باز کن.
۴. از دکمهٔ Share گزینهٔ **Add to Home Screen** را بزن و گزینهٔ **Open as Web App** را روشن کن.
۵. برنامه را یک‌بار در حالی که اینترنت وصل است باز کن؛ فایل‌های اصلی سپس برای استفادهٔ آفلاین ذخیره می‌شوند.

در macOS هم می‌توان همان نشانی HTTPS را باز و به Dock اضافه کرد. روی iPhone و Mac هر کدام پایگاه دادهٔ محلی جداگانه دارند.

## ذخیره‌سازی و پشتیبان

- داده‌های تجاری در `IndexedDB` مرورگر ذخیره می‌شوند؛ `Cache API` فقط فایل‌های ثابت برنامه را برای اجرای آفلاین نگه می‌دارد.
- داده‌ها به‌صورت خودکار بین دستگاه‌ها همگام نمی‌شوند. برای انتقال اطلاعات، در بخش **تنظیمات و پشتیبان** خروجی JSON بگیر و در دستگاه دیگر آن را بازیابی کن.
- پاک‌کردن داده‌های سایت/مرورگر یا حذف پروفایل مرورگر ممکن است داده‌ها را پاک کند. پشتیبان منظم و نگهداری نسخه‌ای از آن در محل امن ضروری است.
- فایل JSON پشتیبان شامل اطلاعات مشتریان و تراکنش‌ها است؛ آن را عمومی یا برای افراد نامطمئن ارسال نکن.

## محدودیت‌های این نسخه

این نسخه یک ابزار مدیریتی محلی و تک‌کاربره است، نه سامانهٔ حسابداری رسمی یا فروشگاه اینترنتی متصل به درگاه. همگام‌سازی ابری، حساب کاربری و سطح دسترسی، اتصال به درگاه بانکی/پست، صدور فاکتور مالیاتی رسمی، مدیریت چند انبار، بارکدخوان و برگشت جزئی اقلام هنوز پیاده‌سازی نشده‌اند. لغو سفارش، تمام اقلام همان سفارش را برمی‌گرداند.

محاسبات گزارش سود، بر اساس قیمت خرید ثبت‌شده هنگام فروش و هزینه‌های واردشده انجام می‌شود؛ در نتیجه کیفیت گزارش به کامل بودن داده‌ها وابسته است. پیش از اتکا در عملیات مالی واقعی، چند دورهٔ آزمایشی اجرا و ارقام را با اسناد خرید و فروش تطبیق بده.

## ساختار فایل‌ها

- `index.html` — پوستهٔ برنامه
- `styles.css` — ظاهر واکنش‌گرا و RTL
- `app.js` — منطق برنامه و ذخیره‌سازی IndexedDB
- `manifest.webmanifest` — مشخصات PWA
- `sw.js` — ذخیرهٔ فایل‌های ثابت برای حالت آفلاین
- `icon.svg` و `apple-touch-icon.png` — آیکون برنامه
- `Start-Mac.command` — راه‌انداز محلی macOS
